# АИС «Библиотека» — учебный прототип

Рабочее Django-приложение, собранное под лабораторные работы по проекту АИС «Библиотека».

## Быстрый запуск на Windows

1. Установите **Python 3.10+** с python.org и включите `Add Python to PATH`.
2. Распакуйте архив в обычную папку без системных ограничений.
3. Дважды запустите **`launch.bat`**.
4. При первом запуске установятся Django и зависимости, создастся БД, миграции и демо-данные.
5. Браузер откроется автоматически: `http://127.0.0.1:8000/`.

Чтобы остановить сервер, вернитесь в окно командной строки и нажмите **Ctrl+C**.

## Демо-учетные записи

- Администратор: `admin` / `admin123`
- Библиотекарь: `librarian` / `library123`
- Читатель: `reader` / `reader123`

Админ-панель: `http://127.0.0.1:8000/admin/`

## Что реализовано

- публичный каталог книг в оформлении, совпадающем со скриншотом лабораторной;
- отдельный раздел авторов;
- регистрация читателя через веб-интерфейс;
- поиск по названию, автору и ISBN;
- отображение доступности экземпляров;
- авторизация;
- роли через штатные механизмы Django (`staff` для библиотекаря/администратора);
- учет читателей;
- выдача и возврат экземпляров с транзакцией;
- запрет выдачи недоступного экземпляра;
- бронирования;
- отчет по просроченным выдачам;
- личный кабинет читателя;
- журнал ключевых операций;
- Django Admin;
- демонстрационный набор книг, совпадающий по смыслу со скриншотами из отчета.

## SQLite и PostgreSQL

По умолчанию используется **SQLite**, чтобы приложение запускалось сразу и не требовало настройки СУБД.

Для лабораторной среды с PostgreSQL задайте переменные окружения перед запуском:

```text
USE_POSTGRES=1
POSTGRES_DB=library_db
POSTGRES_USER=library_app
POSTGRES_PASSWORD=library_pass
POSTGRES_HOST=127.0.0.1
POSTGRES_PORT=5432
```

После этого выполните `python manage.py migrate` и `python manage.py seed_demo`.

## Полезные команды

```bash
python manage.py check
python manage.py migrate
python manage.py seed_demo
python manage.py runserver 0.0.0.0:8000
```

> Это учебный прототип. Демо-пароли нельзя использовать в реальной эксплуатации.
